# 🚀 Spring AI – Live Course Agenda

A **live, hands-on course** designed for **Java & Spring Boot developers** who want to build **production-ready AI applications** using **Spring AI**.

This course follows a **progressive learning path** — starting from GenAI fundamentals and moving all the way to advanced topics like **RAG, Tool Calling, MCP, Multimodality, Testing, and Observability**.

---

## 👨‍💻 Who This Course Is For

- Java developers with basic Spring Boot knowledge
- Backend engineers exploring **GenAI integration**
- Developers tired of writing raw OpenAI / Gemini REST calls
- Anyone who wants to build **real AI systems**, not just demos

> ❌ Not for absolute Java beginners  
> ❌ Not focused on Python-based AI tooling

---

## 🧠 What You Will Learn

By the end of this course, you will be able to:

- Build AI-powered Spring Boot applications
- Integrate OpenAI, Gemini, and local LLMs (Ollama)
- Control AI behavior using prompts, roles, and advisors
- Convert AI responses into **type-safe Java objects**
- Build **stateful AI systems** with chat memory
- Implement **RAG (Retrieval Augmented Generation)**
- Enable AI to **call real tools and databases**
- Work with **MCP (Model Context Protocol)**
- Add **voice, audio, and image capabilities**
- Test, monitor, and observe AI systems in production
